# Changelog

## 0.1.0

Initial public source release accompanying *Beyond Token Scale: Chunk-Level Sparse Autoencoders for Reliable Semantic Feature Discovery*.

- Mean-Chunk, Cross-Chunk, and nested Joint-Chunk implementations, plus Token BatchTopK and Temporal baselines.
- Streaming Qwen3.5 activation extraction, exact occurrence accounting, distributed training, and resumable artifacts.
- Evaluation modules organized by research task; compatibility entry points retained.
- English documentation, a Chinese training guide, reduced and research-scale configurations, and a CPU training example.
- Automated CPU checks and Python package metadata.

Large model weights, activation caches, and prepared experiment artifacts are separate inputs.
